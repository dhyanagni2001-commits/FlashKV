Inside the server

  • poll() event loopNon-blocking sockets with per-client input and output buffers, backpressure and pipelining.
  • RESP2 parserBinary-safe and incremental. Commands split across TCP packets are reassembled, and inline commands work for nc.
  • ExpirationLazy on access, plus a Redis-style active cycle that samples volatile keys 10 times a second.
  • maxmemoryO(1) LRU list with allkeys-lru or noeviction. Evictions are logged to the AOF as DEL.
  • Append-only fileBuffered per event-loop pass, written before replies leave and fsynced every second. Truncated tails are repaired on load.
